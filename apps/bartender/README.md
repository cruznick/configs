# Bartender

Capture the working configuration with `dots-snapshot create`; see
[current-state snapshots](../../docs/SNAPSHOTS.md).

The private snapshot contains a fresh `defaults export` of
`com.surteesstudios.Bartender` and the
installed app version. No private preference data is committed here.

Bartender 7 includes an **Import from Bartender 6…** migration option. Prefer that
supported migration when moving between those versions. Restoring an entire
older preference domain caused startup trouble during the November 2026 recovery;
the current working configuration is the new baseline.
